# i18n Rollout Plan

> Spec: `docs/specs/18-i18n.md`. Convention for every task below: move hardcoded strings into `lang/en/<area>.php` + `lang/id/<area>.php` (same keys; `LangParityTest` enforces it), use `useTranslation().t()` in React and `__()` in controllers, run `sail npm run check`, `sail npm run types:check`, `phpstan`, and the area's tests.
