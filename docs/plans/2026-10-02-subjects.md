# Subjects & Teaching Assignments Implementation Plan

> **For implementer agents:** Spec: `docs/specs/09-subjects.md` (ACs 09-01…09). Conventions: `2026-10-02-roadmap-wave-2-3.md`.

**Goal:** Subject catalog, year-scoped `class_subjects` assignments with passing threshold, teacher course portal, class "Mata Pelajaran & Guru" tab, and roll-over copy.

**Architecture:** Plain CRUD controllers like `Classes/SchoolClassController`. Teacher scope = homeroom **or** any `class_subjects` row, implemented once in `ClassAccess` (extended, not duplicated). Roll-over copy is an extra step inside the existing `RollOverService` transaction.

**Prerequisites:** Plans 1 and 2 merged (abilities, audit log, `grade_level`).

**Blocking questions:** none (per-student electives is a spec open question, not v1).
