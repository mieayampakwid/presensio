# Spec 06 — Reports & Exports (student/class reports + CSV export + live presence board)

## Context

Implements `docs/specs/06-reports.md` — the final spec in the build order (01–05 shipped, 368/368 tests green). Three deliverables:

1. **Student report** — pick a student + date range → per-status counts, attendance rate, day-by-day record list. CSV export.
2. **Class report** — pick a class + range → per-student counts + rate, and a students × dates grid. CSV export. Weekends / `non_school_days` greyed; days without a record blank and not counted in rates.
3. **Live presence board** — read-only today screen (piket room / headmaster): per class checked-in / not-yet-checked-in / checked-out, admin school-wide totals, drill-down of not-yet-checked-in students, *in-building* = evacuation headcount. Polls every 30s, no websockets, no notifications.

**Locked decisions:**
- **Rate formula (user-confirmed 2026-09-20):** `(present + late) / (present + late + absent) × 100` — sick/leave excluded from the denominator by default, shown as their own counts. `null` ("—") when denominator is 0.
- **Include-excused switch (user-confirmed 2026-09-20):** one toggle on both reports — `include_excused` (default off). On → sick + leave enter the rate denominator. Counts/records/grid always show regardless; CSV mirrors the switch state.
- Access per spec 01 scoping, reusing `ClassAccess` (`app/Services/Attendance/ClassAccess.php`): admin → all; teacher → homeroom classes; parent → own children (`guardian_student`); student → self. Class report + board: admin/teacher only.
- Read-only; no caching layer, no deferred props (plain queries at single-school scale).
- Range: default = full current month (school tz); valid ranges capped at 366 days inclusive by **clamping** `to = from + 365 days`; any missing/invalid bound falls back to the full current month (silent-default precedent: `AttendanceController::resolveDate`).
- Privacy (mirrors spec 03 carve-out): student report never exposes `notes` / `override_by_user_id` (visible to students/parents).
- UI language follows the app: English with Indonesian parentheticals (`Sick (Sakit)`); CSV headers/labels match the screen.
- Times go out **pre-formatted `H:i` in the school timezone** (house pattern: `AttendanceController::attendanceRow()`) — no client-side time formatting.

## Existing pieces to reuse (no new abstractions)

- `ClassAccess::classIds(User)` / `canAccess(User, int)` — class scoping; null-guard `class_id` per `UpsertAttendanceRequest` house pattern
- `SchoolSettings` singleton — `timezone()`, `todayDate()` (business date, flips at school midnight)
- `NonSchoolDay` — one `whereBetween('date', …)->pluck('date')` per report request (NOT per-date `isSchoolDay()`, which is one query per call)
- Frontend `STATUS_BADGES` / `METHOD_LABELS` in `resources/js/lib/attendance.ts`; badge mini-grid precedent in `pages/excuses/index.tsx:180-215` (outline = no record, `title` tooltip per day)
- Filter-page template `pages/attendance/index.tsx`: GET `<form>` + `filters` prop + `defaultValue` + `requestSubmit()` auto-submit; native `<select>` with the per-file `SELECT_CLASS` const; native `<Input type="date">` pair (range precedent `pages/excuses/my-excuses.tsx`)
- GET handling house style: **plain `Request` + controller parsing** (no FormRequests on GET indexes — FormRequests are mutation-only in this repo); inline authz via `abort_unless` precedent (`ExcuseAttachmentController::canView`)
- Polling pattern `pages/attendance/my-qr.tsx:20-57`: `setInterval` + `router.reload({ only: [...] })`, cleared on unmount
- `AttendanceFactory` states (`late`, `absent`, `sick`, `leave`, `checkedOut`) for tests; role test provider pattern from `RoleMiddlewareTest`

### 2. Service — `app/Services/Reports/AttendanceReportService.php`
Single class, no state:
- `rate(array $counts, bool $includeExcused): ?float` — locked formula, 1 decimal, `null` on zero denominator; `$includeExcused` adds sick + leave to the denominator. Single source used by both reports and both CSVs.
- `studentReport(Student $student, CarbonInterface $from, CarbonInterface $to, bool $includeExcused): array` — `counts` per status (all 5), `rate`, `records` (day-by-day, ascending by date; fields: date, status, `checked_in`/`checked_out` pre-formatted `H:i` school tz, scan_method — **no notes/override**)
- `classReport(SchoolClass $class, CarbonInterface $from, CarbonInterface $to, bool $includeExcused): array` — `dates` (Y-m-d list), `nonSchoolDates` (set from one `whereBetween` pluck), `rows`: per student `[id, student_number, full_name, counts, rate, statuses => [Y-m-d => status]]` (only days with a record; blanks implicit), students ordered by `full_name`
- `board(Collection $classIds, User $viewer): array` — today's aggregates per class: `enrolled`, `in_building` (status present/late AND `checked_out_at` null — counts bulk-marked/manual presents, safe for headcount), `checked_out` (`checked_out_at` set), per-status counts, `not_checked_in` drill-down list `[full_name, status]` (status null = no record yet), plus `totals` across classes + `as_of` (`H:i` school tz) when the viewer is admin — everything inside this one payload so `only: ['board']` refreshes all of it. Queries: scoped classes with students (eager-loaded — `preventLazyLoading` is on), one `whereIn('student_id', …)->where('date', today)`.
- CSV builders `studentCsv(...)` / `classCsv(...)` — `streamDownload` closures: UTF-8 BOM + `fputcsv`, English headers matching the screen (`NIS, Name, Present, Late, Absent, Sick, Leave, Rate %` + per-date columns `d/m` for the class grid; student CSV = summary block + day-by-day rows); rate column reflects `include_excused`. Private `STATUS_LABEL` map matching `lib/attendance.ts` labels.

### 3. Controllers — `app/Http/Controllers/Reports/` (plain `Request`, no FormRequests)

- `StudentReportController::index` — `resolveStudent(Request, User)`: no `student_id` → null (picker renders, no 403); present → `Student::find` or 404, then `abort_unless` scope: admin pass; teacher `$student->class_id !== null && ClassAccess::canAccess(...)`; parent `$user->guardian?->students()->where('students.id', …)->exists()`; student `$user->student?->is($student)`. ## Gotchas carried into execution
- Date-only columns: keep Y-m-d strings end-to-end; never format from the UTC-midnight cast.
- `SchoolSettings` memoizes per process — tests that touch settings rows must `app()->forgetInstance()`.
- `Model::preventLazyLoading(! app()->isProduction())` is active — eager-load every relation report queries touch, or tests throw.
- Role checks compare `UserRole` enum instances, never strings.
- GET indexes take plain `Request` + controller parsing in this repo — no FormRequests (mutation-only); authz inline with `abort_unless` (404 for bad ids, 403 for out-of-scope).
- Don't call `isSchoolDay()` per date (N queries); one `whereBetween` pluck per request.
- Pint strips "unused" imports — keep the `use RefreshDatabase;` trait line.
- Inertia must not intercept the CSV download — plain navigation (`window.location`), not `router.get`.
- Native checkbox in filter forms: `defaultChecked`, and never the Radix/shadcn Checkbox (doesn't submit in native form posts).
